HOW TO PLAY

  • On phones, use the on-screen directional pad. On computers, use W A S D or the arrow keys. You can only move through open corridors.
  • Find the gold key to unlock the green exit portal.
  • Use Run BFS or Run A* to watch a pathfinding algorithm solve the maze.
  • In Human vs Algorithm mode, race the solver to the exit. The solver follows a shortest valid route.
  • Press P or tap Pause to freeze the run. The challenge timer pauses too.
  • The minimap shows walls, your position, the key, exit and remaining shards.
  • Scoring: +10 per move, +100 for the key or each shard, and +250 for a maze clear.
  • Every fifth Challenge level is a CORE BREACH boss stage: collect every shard before the exit will unlock.
  • Press R or Restart Run to reset your position.

BFS explores equally in all directions. A* uses a distance estimate to guide its search. Both find a shortest path in this unweighted maze.
